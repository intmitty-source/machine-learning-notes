## 一、监督式（有标签/知道答案）

> 就像老师批改作业，有正确答案可以参考。

| 方法 | 原理 | 一句话理解 |
|------|------|-----------|
| 方差阈值 | 去掉变化太小的特征 | "全班成绩都是80分，这个特征没用" |
| 卡方检验 | 计算特征和标签的独立性 | "这个特征和结果有没有关系？没关系就扔掉" |
| 互信息 | 衡量特征对标签的信息量 | "知道这个特征后，猜答案更容易了吗？" |
| F检验 | 线性关系的显著性检验 | "特征和结果是不是线性相关？" |
| L1正则化（Lasso） | 惩罚系数，自动把不重要的压到0 | "不重要的特征直接权重归零，自然被过滤" |
| 基于树模型 | 随机森林/XGBoost 输出特征重要性 | "树在分裂时最常用哪些特征？越常用越重要" |
| 递归特征消除（RFE） | 每轮删掉最不重要的一个，反复迭代 | "一轮一轮淘汰赛，直到选出最强选手" |
| Boruta | 用随机噪声特征做对照组 | "加一堆随机垃圾特征，比垃圾还差的就真是垃圾" |
| Permutation Importance | 打乱某列看模型效果掉多少 | "把这个特征搞乱，模型崩了→说明它重要" |

## 二、无监督式（无标签/没有答案）

> 就像盲人摸象，没有正确答案，靠数据本身的规律。

| 方法 | 原理 | 一句话理解 |
|------|------|-----------|
| 方差阈值 | 去掉几乎不变的特征 | "每个人身高都是170，这列没意义" |
| 相关系数过滤 | 去掉高度相关的冗余特征 | "身高和鞋码高度相关，留一个就够" |
| PCA（主成分分析） | 把多特征压缩成少数主成分 | "100个特征压缩成10个，保留95%信息" |
| 互相关矩阵 | 找出特征之间的冗余关系 | "哪些特征在说同一件事？去重" |
| 基于聚类的特征选择 | 对特征聚类，每组选一个代表 | "把特征分成几组，每组派一个代表" |
| 拉普拉斯得分 | 保留能区分不同样本的特征 | "相似样本在这个特征上差异小→好特征" |
| 无监督Lasso | 用重构误差选特征 | "用最少的特征能不能还原原始数据？" |
| Isolation Forest | 异常检测角度选特征 | "哪些特征最能把异常值区分出来？" |

---

## 三、对比记忆

- **监督式** → 有标签 → 特征和"结果"的关系
- **无监督** → 无标签 → 特征之间"自己"的关系

打个比方：
- 监督式：你知道学生最终成绩，选哪些因素最影响成绩（考试时间、复习时长、出勤率…）
- 无监督式：你不知道成绩，但发现"出勤率"和"课堂参与度"高度重复，去掉一个

## 四、实际项目怎么选？

```
有标签？
├── 是 → 树模型特征重要性（最常用、最省事）
│        → RFE（想要更精确）
│        → Boruta（想要最严谨）
└── 否 → 相关系数去冗余 + PCA 降维
         → 先做聚类再选特征
```
